# 鍼灸 通院記録

医療費控除の申告用に、鍼灸の通院日と支払額を記録するアプリです。

## 使い方

公開ページ：https://onoayami.github.io/acupuncture_manager/

または `index.html` をブラウザで開くだけでも使えます（インストール不要）。

- 通院日・施術費・交通費・メモを記録
- 一度入れた施術費は候補として表示（タップで入力、直接入力も可）
- 年ごと（1月〜12月）の合計と、控除の目安10万円までの残額を表示
- CSV書き出し（Excel対応）、JSONでのバックアップ／復元

## 注意

データは開いたブラウザの localStorage にだけ保存されます。履歴の削除などで消えることがあるため、定期的にバックアップしてください。
